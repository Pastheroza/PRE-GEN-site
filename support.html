Support PRE-GEN

PRE-GEN is useful only while it stays open and neutral. Support pays for the specification, test vectors, libraries and a public test suite. It never pays for a commercial registry.

  • Registering and opting out stay free for the people being depicted.
  • The specification and tests stay current, so anyone can build PRE-GEN without paying anyone.
  • More libraries and a test suite make “works with PRE-GEN” something you can check.
