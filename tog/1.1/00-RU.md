# ToG-L 1.1 и ToG-RS 1.1: что изменилось (для Валеры)

Ветка `claude/tog-universal`, ничего не запушено. Тексты 1.0 не тронуты.

**Что изменилось, в пяти строках**
1. Вместо фиксированной проверки личности есть три уровня уверенности: 1 канал, 2 документ, 3 квалифицированная подпись. Обычное «да» работает с уровня 1, как в PRAMPTA.
2. Одна общая доверенность (Delegation) заменила «Authorised Person»: фан-клуб, агентство, реестр получают ограниченную по времени и объёму власть, отзывается бесплатно.
3. Реестр определяется функциями: только «нет», уровни, сделки и деньги. Нагрузка пропорциональна функциям; любая модель оплаты, государственные тоже.
4. Сервис поверх реестра (портал, каталог, маркетплейс) не реестр и ничего не подписывает. Никто не может расширить разрешение, кроме самого Holder (его доверенность считается его актом).
5. Ядро не тронуто: решает Holder, «нет» бесплатно и всегда, полы, без водяных знаков и распознавания.

**Коммерция.** Бесплатной открытой коммерческой лицензии нет: §3 не расширен. Holder может: для всех некоммерческое; коммерческое, включая рекламу за $0, только сделкой с каждой стороной.

**Твои случаи.** Да на канале: уровень 1. Реклама только по документу: условие в Statement «уровень 2» плюс сделка. Фан-клуб: доверенность. Бесплатный реестр: функции «нет» и «уровень 1». Госреестр с eID: уровень 2 или 3. Реестр только для «нет»: только базовая функция. Несовершеннолетний, интим: полы без изменений. Отзыв доверенности посреди сделки: сделка остаётся, Holder может выйти из неё. Закрытие реестра: передача, доверенность заканчивается.

**Длина.** Лицензия 13 003 слов против 12 752 (на 2% длиннее), RS 5 074 против 5 075, deed короче на 8%. Короче лицензию можно, вынув Платформы и «взлом» в отдельные модули (минус около 2 000 слов).

**Решения для тебя**
1. Вынести Платформы и «взлом» в отдельные модули в 1.2? Рекомендую: да.
2. Оставить уровень 1 для «да» даже для известных людей (риск: самозванец с фан-аккаунтом открывает некоммерческое)? Рекомендую: да, это твоя политика; «нет» настоящего Holder всегда сильнее.
3. Доверенность заканчивается при смене реестра. Переносить её при Move? Рекомендую: нет, подтверждать заново.
4. Ставить сделке минимальный уровень 2 по умолчанию? Рекомендую: нет, решает Statement.
5. Реестр без уровня 2 не принимает «нет» от родителей за детей. Принять? Рекомендую: да.
6. Вынести пины спецификаций в подписанный список Стюарда. Рекомендую: да.
