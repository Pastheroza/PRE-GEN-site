Apply for a prefix

Any registry can join PRE-GEN on the same terms, the first one included. Fill this in, check your prefix, and send it. Applications are public: prefixes are assigned in the open (PG codes §9), so the form opens a GitHub issue with your answers for you to submit.

Prefix

Four letters from ABCDEFGHJKMNPQRSTVWXYZ — no digits, no I, L, O or U.

4. Endpoints

HTTPS, no credentials, query or fragment. It serves POST /v2/requests, GET /keys and /.well-known/pregen-registry.json.

5. Keys

Send the same list to the steward by a second channel too (an email from your domain, or a signed message), so a stolen account cannot list someone else's key.

6. Conformance

You need a free GitHub account to submit. Nothing is sent anywhere until you press Submit new issue on GitHub. Prefer to write it yourself? Use the issue template.

What happens next: the steward checks the application against the listing conditions, confirms your keys out of band and signs a new directory. A listing is never removed or given to another registry; it can be revoked.
