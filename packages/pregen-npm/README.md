# pregen

The PRE-GEN verification library under its short name: `npm install pregen`
gives you exactly [`@pregen/verify`](https://www.npmjs.com/package/@pregen/verify),
the same as `pip install pregen` in Python.

```js
import { loadDirectory, verifyDecision } from "pregen";
```

Documentation: [`@pregen/verify`](https://www.npmjs.com/package/@pregen/verify) ·
[pregen.org/docs/sdk](https://www.pregen.org/docs/sdk). Apache-2.0.
