# Draft: the ToG funnel — pregen.org/tog hands closed answers to a registry

**UNRELEASED working draft, not part of PRE-GEN.** Nothing here changes what an implementation of the standard
must do. The legal texts it names (ToG-L-1.0, ToG-B-1.0, prampta-likeness v2) are drafts, not final. Vectors:
`test-vectors/tog-generator.json` (generated by `tools/tog_generator_vectors.py` from the approved reference
`tools/tog_generator.py`).

## The fragment `tog=v1`

```
{tog_start}#tog=v1.<base64url, no padding, of the canonical JSON of the answers>
```

- Canonical JSON: keys sorted, no spaces, ASCII only; arrays in the generator's own order, never sorted.
- Members: `age` (`"18+"` | `"13-17"`, always), `decision` (`"no"` | `"approve_all"` | `"rules"`, always);
  if the decision is not no: `for` (non-empty, ⊆ `fun, news, paid` in that order), `never` (⊆ `vice, weapons,
  violence, gambling, money, health, religion, ads, endorse, fashion` in that order), `voice` (boolean); `floor`
  (`"each"` | `"project"` | `"video"`, the kind of lowest price, never an amount) iff `paid` is in `for`.
- Under 13 is never encoded. A 13-17 answer is only ever a no.
- Decode is strict and never repairs: at most 1024 characters; `tog=` then `v1.`; base64url alphabet only, no `=`;
  UTF-8 JSON; the exact member set; every value in its closed set; and re-encoding the answers gives back exactly
  the input (this rejects padding, non-canonical bits, key order, spaces, duplicate keys and escapes).
- Results: `ok` with the answers; `unknown_version` (anything after `tog=` but `v1.`); `minor` (13-17 with a yes);
  `malformed` (everything else). The person sees every answer and the card again at the registry before anything
  is signed, so a corrupted link costs nothing.

**Privacy.** The answers are closed codes, not personal data. They ride only in the fragment, which browsers never
send in a request or a Referer. The year of birth, a name and an email never enter it; the query string is never
used. The registry reads the fragment and removes it from the address at once.

## The registry chooser

The page reads the signed directory (`/registries.json`) and offers an entry only if its `prefix` is non-empty, it
is not revoked, and its `tog_start` is `https:` with the same origin as its `website` (default port and letter case
do not matter), without credentials, query or fragment. The button is a top-level navigation to
`tog_start + "#" + fragment`. Until a steward lists a `tog_start`, the page says "No registry takes ToG codes yet."

On `localhost` only, the page reads `/test/tog-local/registries.json`, signed by the ephemeral key in
`/test/tog-local/steward.json` (`node test/tog-local.mjs [origin]`), and then also allows `http://localhost`.

## A company

A company answers the same questions without voice and gets files for its own site: `/terms-of-generation`,
`/.well-known/tog.json`, the `<link rel="tog">` line and the footer link, under the handle `tog:<domain>`. No
registry code. The files are an unsigned draft: until signed with the company's passkey, AI apps read them as a no.
