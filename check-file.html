Check a file

See who approved a video after it was made: whose likeness, under which licence, who approved it, and whether the approval still stands today.

  1. Fingerprint of the file
  2. Record
  3. Signature
  4. Status today

What an approval after generation never says

  • It was recorded after the video existed.
  • It is not a permission given before generation.
  • It says nothing about whether the video is AI-generated or real.

How it works: the page computes the file's fingerprint (media/1, a hash of every byte of the file except the boxes that carry the record), reads the records in the file's metadata and asks the registries for any they hold under that fingerprint, checks each registry's signature against the signed list of registries, and asks each registry whether its approval still stands. Only the fingerprint is sent to the registries, never the file. Editing the file in any way, even its title, gives it a new fingerprint.

ToG Protocol (Terms of Generation Protocol). Earlier versions of this protocol were published as Prompt Protocol and as PRE-GEN Protocol. It is the same protocol under its current name.
