# Security

Report privately, never in a public issue:
https://github.com/Pastheroza/PRE-GEN-site/security/advisories/new

- **A stolen registry operator key**: the steward confirms it with the operator through its
  listed contact and revokes the key in the directory (`spec/tools/STEWARD.md`).
- **A flaw in the libraries (`pregen`, `@pregen/verify`), the reference registry or the
  specification**: include the version and the smallest input that shows it.

Fixes ship as new package versions; the directory and the steward key are described in
`spec/PG-CODE.md` §9.1.
